# ETS100 逆向工程资料（E听说 PC 学生端）

本仓库是对 **讯飞易听说「E听说」学生端 PC 版 5.7.9**（STIC 3.0.76 / CEF 91 壳）的逆向分析资料集合，包含架构、协议、前端、原生层、本地数据、更新链与运行时验证报告，以及可复现的脚本与脱敏机读样本。

> 分析对象为作者本机自有的软件副本；所有结论来自静态分析与目标自身产生的日志/缓存，以及作者主动启动实例后的 CDP 运行时观察。仓库不包含原始安装包、原始日志、个人信息或大体积反编译产物。

## 目录

```
docs/                 11 篇中文报告（从 REPORT.md 开始）
data/                 脱敏后的机读数据
  api/                端点清单、签名样本（已脱敏）、签名参考实现、更新器签名证明
  frontend/           路由、action 清单、插件 JS 权威 action 表、在线 chunk 清单
  native/             14 个原生 PE 的导出/导入/插件 ABI/能力面
  db/                 本地 SQLite 配置库数据
runtime/              运行时验证：插件 JS 封装层、活体请求元数据
scripts/              本次分析的全部脚本（缓存解码、签名验证、密钥流、CDP 抓取等）
```

## 核心成果

| # | 成果 | 验证 |
|---|---|---|
| 1 | API 签名 `MD5(pid + time + base64(body) + 内嵌密钥流)` | 历史日志 333/334 + 运行时 68/68 |
| 2 | 更新器签名 `MD5("grlx" + time秒 + base64(body) + key)` | 3/3 |
| 3 | 登录字段 AES-128-ECB 加密与硬编码密钥 | 3/3 密文解密 |
| 4 | 前端 Chromium blockfile 缓存解码 / 在线全量 chunk（188 个） | 100% 覆盖 |
| 5 | 题库包 ZipCrypto 口令算法 | 24/24 解包 |
| 6 | 插件 ABI（4 导出）、9 通道 115 个 action、壳自定义 scheme | 三方交叉 |

详见 `docs/REPORT.md`。
